# henryforrest.github.io

Source for my portfolio site, live at [henryforrest.github.io](https://henryforrest.github.io/).

Hand-written HTML and CSS with no build step or framework, hosted on GitHub Pages. Every push to `main` is live within a minute.

## Pages

| File | Purpose |
|---|---|
| `index.html` | Home: selected work, about, stack, contact |
| `market-brief.html` | Case study for Market Brief, my iOS app on the App Store |
| `perfect-circle.html` | Case study for Perfect Circle, my daily-challenge iOS game |
| `dissertation.html` | Case study for my final-year dissertation on reinforcement learning for trading |
| `case.css` | Shared styles for the case-study pages |
| `cv.pdf` | Current CV |
| `logos/` | Logos used on the site |

## Working on it

Open `index.html` in a browser, or serve the folder locally:

```sh
python3 -m http.server 8000
```
